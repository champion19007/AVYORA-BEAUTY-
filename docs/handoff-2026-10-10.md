  - One ingredient-based eligibility check for catalogue and owned products.
  - Hard conflicts are removed, and invalid plans can't be shown as usable, saved or bought (checked again on the server).
  - Full-INCI identity checks.
  - Usage limits apply to every scheduled product.
  - Versioned answer adapter; quiz evidence with correlation control.
  - Categorical Bayesian validation.
  - A feasible-budget search.
  - Explanations built from the actual decision trace.
- **Privacy:**
  - No linked skin telemetry.
  - Whole-envelope log and monitoring scrubbing.

  - Privacy actions keep working with features switched off.
- **Scan:**
  - Race-safe staged uploads.
  - Bounded and cancellable requests; camera released in every exit path.
  - 4 MB limit.
  - Scan-to-routine hand-off.
  - Inference stays disabled.
- **Desktop journeys:**
  - Header search with category and concern entry points.
  - Shop filters with URL state.
  - Comparison of up to three products.
  - Real review aggregates and "Top rated".
  - Correct canonicals and noindex.
  - Structured delivery text.

  - Sample/verified catalogue modes.
- **Onboarding:** a record validator with CLI and admin preview, a synthetic example, and an image-slot specification.

## Feature flags

| Flag | Effect |
| --- | --- |

## Payments: Cashfree replaces Razorpay (2026-10-09)

- Online checkout now uses Cashfree (`src/lib/cashfree.ts`; routes `api/payments/cashfree/{create,verify}`, webhook `api/webhooks/cashfree`, return page `/checkout/return`). Razorpay code stays only so reconciliation can still settle older Razorpay orders; reconciliation picks the provider per order.
- Env: `CASHFREE_APP_ID`, `CASHFREE_SECRET_KEY`, `CASHFREE_ENV` (see `.env.example`). The webhook is signed with the secret key; register `https://DOMAIN/api/webhooks/cashfree` in the Cashfree dashboard before launch (it cannot reach localhost, so sandbox runs rely on the return-page verify plus reconciliation).
- Sandbox run on the acceptance env: order AVY-H3C25D, ₹728, paid with Cashfree's test UPI id; the return page verified with Cashfree, the order went to paid/approved, and the bag was cleared.
- Not yet exercised: the hosted Cashfree page itself (the in-app test browser blocks one of Cashfree's scripts, so payment was submitted through Cashfree's sandbox pay API for the same session), and a real webhook delivery. Do both on a staging URL in a normal browser.
